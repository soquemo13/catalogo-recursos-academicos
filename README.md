# Catálogo de recursos académicos

Proyecto académico para preparar la estructura inicial de una aplicación que permitirá registrar y consultar libros, sitios web, videos, artículos y herramientas de software.

## Objetivo

Aplicar el flujo de trabajo con Python, Git y GitHub, incluyendo control de versiones, ramas, colaboración y Pull Requests.

## Estructura general

- `app/`: código fuente.
- `data/`: registros de ejemplo.
- `docs/`: alcance, criterios, respuestas y evidencias.
- `tests/`: pruebas básicas.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Visual Studio Code

## Preparación del entorno

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

En Windows, activa el entorno con:

```powershell
.venv\Scripts\activate
```
