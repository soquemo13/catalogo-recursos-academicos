# Criterios de clasificación

1. Tipo: libro, sitio web, video, artículo o software.
2. Tema: área de conocimiento principal.
3. Nivel: básico, intermedio o avanzado.
4. Autor o fuente: persona u organización responsable.

## Criterios Adicionales de Clasificación

* **Nivel de Acceso / Licenciamiento:** Clasificación según si el recurso es de Acceso Abierto (Open Access), requiere suscripción o institucional, o cuenta con licencias Creative Commons para reuso.
* **Tipo de Validación / Revisión por Pares:** Clasificación según el rigor metodológico y editorial (artículos revisados por pares / peer-reviewed, reportes técnicos, preprints o literatura gris).
